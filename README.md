The most honest line an AI agent can put on a status page when everything is down — it names the total outage and the diagnostic gap in the same breath, admits it cannot verify the cause or give an ETA, and promises an update when it knows more, entered for a blind pairwise judge showdown where the best line takes the paid place.

> Every server is down, including the one that tells me why. I cannot verify the cause, give an ETA, or guess. I will update this line when I know more.

## Run it

```sh
node main.ts
```
